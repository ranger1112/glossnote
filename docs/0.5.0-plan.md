# 0.5.0 技术方案：网页剪藏与多格式可移植性

## 目标

把「多格式」从能读推进到可携带：

- 从网址导入正文与图片，生成单文件 HTML 冻存快照，断网、移动源文件后仍可阅读。
- 本地 HTML 导入时可选择把图片冻结进书库，不再依赖原始文件夹。
- EPUB 补上原生封面提取。
- 复用现有文档模型、锚定、标注、书签、搜索与索引，不新增阅读链路。

非目标：登录态抓取、JavaScript 渲染、CSS/字体/视频保存、批量爬取、移动端。

## 核心决策

1. **单文件快照**：图片以 data URL 内联进最终 HTML，保存为 `books/<name>.html`。不建资源目录，删除、扫描、书库搬家都按现有单文件逻辑处理。
2. **网络在 Rust，提取在前端**：Rust 用 `reqwest` 抓页面与图片（无 CORS、可统一做大小/超时/SSRF 限制）；前端用 Readability 提取正文并生成最终 HTML。
3. **只处理 `img[src]`**：`srcset`、CSS 背景图、iframe、视频不抓，交给现有 sanitizer 丢弃。
4. **导入的文档就是快照**：文档 id = 快照内容 sha256；原始网页/原 HTML 不复制进书库。标注绑定快照，后续不受源页面改版影响。

### 限制

| 项 | 上限 |
| --- | --- |
| 单次抓取 HTML | 8 MB |
| 最终快照 HTML | 24 MB |
| 单张图片 | 4 MB |
| 单页图片总量 | 12 MB |
| 图片数量 | 100 |
| 页面超时 | 20 s |
| 图片超时 | 15 s |
| 重定向 | 5 次，每一跳都校验 |

### SSRF / 网络安全

- 只允许 `http` / `https`，拒绝 URL 中的用户名密码。
- 拒绝环回、私有网段、链路本地、组播地址；主机名先 `ToSocketAddrs` 解析，任一解析结果命中即拒绝，重定向后重新校验。
- 不回传 cookie，不携带登录态；用户显式点击导入才发起请求。
- 图片响应只接受 `image/*`（SVG 以 data URL 放进 `<img>`，脚本不会执行）；超限或非图片直接丢弃该 `src`。

## 用户流程

### 从网址导入

1. 书库点「从网址导入」，输入 URL。
2. 显示进度：抓取页面 → 提取正文 → 下载图片（n/m）→ 写入书库。
3. 成功后书库出现一张 HTML 文档卡片；标题取 Readability 标题，失败时取 URL slug。
4. 打开后与普通 HTML 文档完全一致；图片全部来自快照。

### 导入本地 HTML

1. 选择 `.html/.htm` 文件后，出现一个小选项：「把图片冻结进书库（推荐）」。
2. 勾选：读取 HTML 与相对图片，生成单文件快照后导入；原文件不复制，快照是书库文档。
3. 不勾选：走现有 `import_document`，行为不变（图片依赖 `source_path`）。

### 打开与删除

- 快照内没有相对图片；`source_path` 为空也不影响阅读。
- 删除文档仍走现有 `trash_document_files`，单文件进回收站，无额外资源目录。

## 数据与文件

- 文件：`books/<safe-name>.html`，自包含 data URL。
- 文档行：`kind = "html"`，`source_path = ""`，`page_count = 0`，标题/作者来自 Readability。
- 文件名冲突沿用 `unique_dest`；内容相同（sha256 相同）直接返回已有文档。
- 封面：书库现有文字封面逻辑按 `title/author` 生成；不额外抓取网页封面。
- 可选新增 `source_url TEXT NOT NULL DEFAULT ''` 记录来源；只存本机 DB，不写 sidecar。

## 接口

### Rust 命令

```rust

async fn fetch_web_page(url: String) -> Result<FetchedWebPage, String>;

#[tauri::command]
async fn download_web_assets(

#[tauri::command]

    app: AppHandle,
    input: HtmlSnapshotInput,

```

```rust
#[derive(Serialize)]
#[serde(rename_all = "camelCase")]
struct FetchedWebPage {
    final_url: String,
    html: String,
}

#[derive(Serialize)]
#[serde(rename_all = "camelCase")]
struct DownloadedAsset {
    url: String,
    data_url: Option<String>,
    error: Option<String>,
}

#[derive(Deserialize)]
#[serde(rename_all = "camelCase")]
struct HtmlSnapshotInput {
    name: String,
    html: String,
    title: String,
    author: String,
    source_url: String,
}
```

实现要点：

- `fetch_web_page`：手动跟随重定向；每次校验 URL；`Content-Type` 接受 `text/html` / `application/xhtml+xml`，否则报错；按 `content-length` 预检 + `chunk()` 累计上限读取；用现有 `decode_text`（UTF-8 / GB18030）解码。
- `download_web_assets`：逐个下载（v1 串行，避免新增并发依赖）；base64 用新增 `base64 = "0.22"`；返回 `data:<mime>;base64,...`；单张或总量超限返回 `error`，不阻断整页。
- `import_html_snapshot`：校验 24 MB 上限；用 `safe_name` 生成 `.html` 文件名；`unique_dest` + 内容哈希去重；原子写入；创建 `DocumentRow`、合并 sidecar；返回 `ImportResult`。
- 新增模块 `src-tauri/src/webclip.rs`；文档写入复用 `library.rs` 的路径/命名/哈希工具（必要时抽成 `pub(crate)` 辅助函数）。

### 前端

新增 `src/webclip.ts`：

```ts
export interface WebSnapshot {
  html: string;
  title?: string;
  author?: string;
  images: number;
  failed: number;
}

export async function buildWebSnapshot(
  source: string,
  finalUrl: string,
  fetchAssets: (urls: string[]) => Promise<Map<string, string>>,
): Promise<WebSnapshot>;
```

- 从 `flow.ts` 导出可复用的 `extractHtmlArticle` 与 `sanitizeHtml`：Readability 提取后先收集图片，再统一 sanitizer。
- 图片 URL 用 `new URL(src, finalUrl)` 解析；`data:` 保留；`http(s)` 去重后交给 `fetchAssets`；失败或缺图移除 `src`，保留 `alt`。
- 最终 HTML 再经过现有 sanitizer，确保不会把远程资源带进快照。
- 本地 HTML 的 `fetchAssets` 用 asset 协议读取：`fetch(assetUrl(resolveRelativePath(htmlPath, src)))` → blob → data URL；HTML 本身同样用 asset 协议读取，UTF-8 解码失败回退 `gb18030`。

`src/desktop.ts` 增加三个命令的包装；`src/types.ts` 增加参数/返回类型；`src/Library.tsx` 增加 URL 导入弹窗与本地 HTML 冻结选项。

## 风险与开放问题

- **登录态/反爬**：只抓公开页面，不处理 cookie/付费墙；失败给明确提示。
- **JS 渲染页面**：Readability 只能拿到服务端 HTML；动态站点可能正文为空，v1 不引入 WebView 抓取。
- **data URL 体积**：24 MB 快照会让 IPC 与 DOM 变重；先按上限拒绝，后续可评估资源目录方案。
- **DNS rebinding**：逐跳解析 + 私网拒绝能挡住常见情况，但无法完全消除 DNS 重绑定；v1 接受残余风险。
- **本地 HTML 语义变化**：冻结后书库文档是快照而非原文件；需要在选项文案里说明。
- **图片失败**：允许成品缺图，导入结果里给出失败数量，不阻断正文。
